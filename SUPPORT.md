# Support

## Getting Help

### Documentation

Start with the [README](README.md) for installation and usage instructions.

### Issues

Report bugs and request features via the
[GitHub issue tracker](https://github.com/mheci/vibes/issues).

Before opening a new issue:

- Search existing issues to avoid duplicates.
- Provide your image tag, hardware details, and reproduction steps.
- Include relevant logs or error messages.

### Discussions

For questions, troubleshooting, and community discussion, use
[GitHub Discussions](https://github.com/mheci/vibes/discussions) if enabled.

### Security

Report security vulnerabilities privately via the
[Security Advisory tab](https://github.com/mheci/vibes/security/advisories/new).
See [SECURITY.md](SECURITY.md) for the disclosure policy.

## Commercial Support

This project is maintained by a single maintainer. No commercial support is
available at this time.
